# **App Name**: CodeCanvas

## Core Features:

- Multi-Tab Code Editor: Provides distinct editable areas for HTML, CSS, and JavaScript using an integrated code editor library, remembering content when switching tabs.
- Real-time Live Preview: Instantly renders the combined output of HTML, CSS, and JavaScript as the user types.
- Resizable Panes & Layout Views: Allows users to dynamically adjust the size of the code and preview panes and switch between various viewing layouts (e.g., side-by-side, top-bottom).
- Local Session Persistence: Automatically saves the user's entered code in the browser's local storage, restoring their work across sessions.
- Smart Code Suggestions Tool: Leverages generative AI to provide intelligent suggestions for code completion, optimization, or best practice adherence in the active editor.
- External Library Inclusion: Supports the inclusion of third-party JavaScript and CSS libraries by directly referencing CDN links within the HTML pane.

## Style Guidelines:

- Color Scheme: A sophisticated dark theme to enhance focus and reduce eye strain for developers, evoking professionalism and a sleek, technical aesthetic.
- Primary Color (interactive elements, highlights): A clean, bright sky blue for clarity and actionable items, represented as RGB hex: #85BBEE.
- Background Color (main canvas): A dark, muted blue-gray for the primary work area, providing a calm and immersive environment, represented as RGB hex: #24282D.
- Accent Color (subtle details, active states): A vibrant medium violet to provide a touch of creativity and clear contrast without being overly distracting, represented as RGB hex: #7F7FE5.
- Headline and body text font: 'Inter' (sans-serif), chosen for its modern, clear, and objective readability suitable for UI elements and explanatory text.
- Code font: 'Source Code Pro' (monospace), specifically selected for its excellent legibility and common usage in development environments, ensuring code is clear and easy to parse.
- Utilize simple, functional line icons for navigation, controls, and editor actions, maintaining a minimalist and modern appearance consistent with a development tool.
- Adopt a flexible box and grid layout system to enable seamless resizing and dynamic view switching, ensuring responsiveness across all device sizes as required for a code editor.
- Incorporate subtle, quick transitions for tab switching and pane resizing to provide fluid user feedback without distracting from the core coding experience.
